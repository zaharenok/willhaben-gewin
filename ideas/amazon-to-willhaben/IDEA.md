# IDEA — Willhaben vs Amazon: расширение Chrome для сравнения цен

**Дата:** 2026-11-01
**Статус:** идея, не начато

## Суть

Chrome-расширение (Manifest V3), которое при просмотре товара на Amazon (amazon.de) показывает оверлей/бейдж: сколько ты **сэкономишь**, если купишь этот же товар б/у на Willhaben (willhaben.at).

Пример: на странице товара Amazon за €89 расширение показывает:
> 💚 На Willhaben б/у: ~€35 → экономия €54 (61%)

## Как это работает (MVP)

1. **Content script** на `amazon.de/*/dp/*` извлекает: название товара, бренд, EAN/ASIN, цену.
2. **Поиск на Willhaben**: запрос к `willhaben.at` (поиск по названию/EAN через их публичный поиск или scraping через offscreen/background fetch).
3. **Сопоставление товаров**: нечёткое сравнение названия + бренда (MVP: ручное подтверждение пользователем из списка найденных).
4. **Оверлей**: бейдж/панель на странице Amazon с ценой б/у, разницей в € и %, ссылкой на объявления Willhaben.

## Технический стек

- Manifest V3, TypeScript, Vite (crx-справка: `@crxjs/vite-plugin` или `vite-plugin-web-extension`)
- Без бэкенда для MVP (всё в браузере)
- Позже: опция для willhaben API через их app-эндпоинты (риск блокировок)

## Открытые вопросы / риски

- Willhaben не имеет публичного API — поиск через scraping; риск блокировки/изменения вёрстки. Альтернатива: открытие результатов поиска в новой вкладке без парсинга (MVP-минимум).
- Сопоставление товаров б/у неточное (состояние, комплектация) — нужно показывать диапазон цен (мин–медиана), не одну цифру.
- Только Австрия: amazon.de + willhaben.at; другие маркетплейсы потом.
- Правила расширений Chrome: scraping сторонних сайтов из расширения — серая зона, но для личного использования ок.

## Следующие шаги

1. Прототип content script: извлечение названия+цены со страницы Amazon (проверка селекторов).
2. Решить канал данных Willhaben: парсинг поиска vs просто ссылка с pre-filled запросом.
3. UI оверлея: бейдж возле цены Amazon.
4. Fuzzy-match и подтверждение пользователем.
